# Frosty Foods — WordPress theme (build)

Download **[frosty-foods-wordpress-theme.zip](frosty-foods-wordpress-theme.zip)** and upload it in
WordPress › Appearance › Themes › Add New › Upload Theme, then activate it.

Dashboard: open the site footer › **Dashboard · لوحة التحكم** — default code `2026`.

Source lives on the `main` branch (`node tools/build-ready-to-go.js`).
